# Video Analyzer - Private Local Project

⚠️ **IMPORTANT: This is a private, local-only project. Do NOT push to any remote repository.**

## Overview
This is a PyQt5-based video analysis application that extracts and processes video information including:
- Scene/shot change detection
- Binary image analysis
- Video decomposition into clips
- Analysis visualization

## Setup
1. Install dependencies from `requirements.txt` (create if needed)
2. Ensure your current working directory is set correctly before running
3. Run: `python Video_player_v2.py`
